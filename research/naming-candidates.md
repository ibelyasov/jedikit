## Как читалась проверка

- Для GitHub выполнен поиск репозиториев по точному/кавычечному имени через подключённый GitHub-поиск. В дополнение проверен предполагаемый slug владельца `ibelyasov/<slug>` через GitHub API: все 12 URL вернули `404 NOT_FOUND` на дату проверки. Это проверяет только отсутствие репозитория у текущего владельца, не глобальную доступность имени. Поисковые выдачи могут быть неполными; ссылки на выдачу и заметные совпадения приведены в таблице.
- Для USPTO выполнен exact Wordmark search по каждому имени в Trademark Search. Для 11 имён интерфейс показал `Live 0 / Dead 0`; для **MindRelay** найден результат serial `99306527`, registration `N/A`, class 041 (образовательные услуги, в описании — personal-finance education) ([карточка USPTO](https://tmsearch.uspto.gov/search/search-results/99306527)). USPTO описывает такой «knock-out» как первый шаг, после которого нужно искать похожие обозначения и связанные товары/услуги ([Federal trademark searching](https://www.uspto.gov/trademarks/search/federal-trademark-searching), [likelihood of confusion](https://www.uspto.gov/trademarks/search/likelihood-confusion)).
- Платформа поиска товарных знаков Роспатента была открыта по официальному адресу, но в этой сессии UI завершился тайм-аутом/пустым DOM; поэтому отсутствие российских совпадений **не утверждается** ([официальная платформа Роспатента](https://searchplatform.rospatent.gov.ru/trademarks)). Аналогично, WIPO Global Brand Database и EUIPO TMview нужно прогнать отдельно перед публикацией ([WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database), [EUIPO TMview](https://www.tmdn.org/tmview/)).
- Упомянутые страницы продуктов/сервисов ниже — быстрый web-use/confusion scan, а не результаты официального реестра и не доказательство наличия или отсутствия товарного знака.
