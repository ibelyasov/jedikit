# Навигатор включается по запросу

`jedikit` — read-only навигатор без провайдера и `tools.json`, владелец общей карты команд и человеческого словаря JediKit. Он включается по запросам «что умеет JediKit», «куда это записать», «с чего начать день», «какой скилл…» и отвечает группами по результату, двумя-тремя примерами запросов и следующим шагом. Связку дня показывает навигатор: Daily open (`jedikit-tasks`) → План дня (`jedikit-planning`), вечером Daily close.

Навигатор не пишет и не выполняет чужие сценарии сам. Он не является обязательным маршрутизатором перед каждым запросом: такой посредник добавлял бы лишний шаг и единую точку отказа. Хост предоставляет остальные скиллы JediKit и внешний `grill-me` для глубокого уточнения ([ADR 0013](0013-clarification.md)). Правила связи — [ADR 0012](0012-skill-composition.md), основания — [досье композиции](../../research/agents/skill-composition.md).
