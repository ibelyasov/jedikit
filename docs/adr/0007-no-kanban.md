# Kanban не поддерживается

У Дорофеева нет нормы про kanban, исследования досок в основном командные, а колонка `Done` в SingularityApp связана с жизненным циклом задачи. `jedikit-tasks` не подключает toolset `kanban`, не читает и не меняет доски. Разделы и теги поддерживаются (см. `research/tasks/structure.md`).
