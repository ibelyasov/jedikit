# Папка определяется по наличию дочерних проектов

Пользователь группирует десятки мелких проектов вложенными проектами. Скилл считает папкой любой проект с дочерними проектами, а проектом — любой проект без них. Пометок, служебных тегов и записей в памяти для этого нет. Следствие: крупный проект, разбитый на подпроекты, тоже считается папкой, и его следующие шаги живут в подпроектах.

## Considered Options

- Отметка папок в памяти агента: состояние, которое расходится с деревом в приложении.
- Соглашение об именах или служебный тег: засоряет пространство пользователя.
