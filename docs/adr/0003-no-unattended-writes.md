# Фоновые проверки только читают

Расписание хоста запускает скиллы только read-only. Найденные дубли тегов, пустые разделы, проекты без шага и прочая гигиена складываются в предложения для weekly и выполняются после одного подтверждения. Владелец хотел часть обслуживания делать в фоне без вопросов, но нет данных, что агент надёжно угадывает смысл чужих категорий, а ошибочное фоновое объединение или удаление молча ломает систему пользователя.
