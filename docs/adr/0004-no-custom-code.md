# Никакого собственного кода

Репозиторий содержит только инструкции скиллов, portable `plugin.json`, `skills/*/tools.json` и документы. `tools.json` — декларативные данные внешнего контракта с Hermes, а не код. MCP-декларации и инфраструктура модельных проверок в пакет не входят. Проверки — официальные валидаторы Hermes (`hermes plugins validate . --json`, `hermes plugins doctor . --ci`), `git diff --check` и независимое ревью агентом; модельных прогонов нет. Они проверяют `skills/` как portable plugin; отдельного валидатора обычной коллекции для `skills.external_dirs` у Hermes нет. Exit `0` не доказывает точный inventory пяти скиллов: отчёты и warnings читаются. Собственный сборщик, fake MCP или replay-проверки проверяли бы сами себя и неоправданно усложняли пакет инструкций. Новый код появляется только если конкретную проверку нечем закрыть штатно, и только после отдельного решения.
