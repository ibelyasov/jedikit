# Никакого собственного кода

Репозиторий содержит только инструкции скиллов, manifests и документы. Проверки — официальные валидаторы (`claude plugin validate --strict`, `hermes plugins validate`, `hermes plugins doctor --ci`) и поведенческие evals штатным `claude plugin eval` с mock-ответами провайдеров. Прежние ~4600 строк Python (сборщик, fake MCP, release policy, replay ledger) удалены: они проверяли сами себя дороже, чем стоили два markdown-скилла. Новый код появляется только если конкретную проверку нечем закрыть штатно, и только после отдельного решения.
