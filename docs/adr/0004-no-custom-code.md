# Никакого собственного кода

Репозиторий содержит только инструкции скиллов, manifests, `skills/*/tools.json` и документы. `tools.json` — декларативные данные внешнего контракта с хостом, а не код. MCP-декларации и инфраструктура модельных проверок в пакет не входят. Проверки — официальные валидаторы (`claude plugin validate --strict`, `hermes plugins validate`, `hermes plugins doctor --ci`), `git diff --check` и независимое ревью агентом; модельных прогонов нет. Прежние ~4600 строк Python (сборщик, fake MCP, release policy, replay ledger) удалены: они проверяли сами себя дороже, чем стоили два markdown-скилла. Новый код появляется только если конкретную проверку нечем закрыть штатно, и только после отдельного решения.
