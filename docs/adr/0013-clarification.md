# Доспрос полей отделён от уточнения намерения

Скилл использует известное и сам собирает все блокирующие пробелы полей одним сообщением, по пункту на пробел. Известные и необязательные данные не спрашивает. Относительные даты разрешает по правилам домена и показывает конкретную дату в результате без повторного подтверждения. Такой доспрос нужен для выполнения команды, а не для повторного получения уже данного разрешения ([досье уточнений](../../research/agents/clarification.md)).

Глубокое уточнение намерения — редкий отдельный случай, например «хочу завести привычку» без ясного поведения и цели. Его выполняет внешний `grill-me`, объявленный требованием к хосту. Если скилла нет, JediKit называет его и рекомендует установить средствами хоста; собственное интервью не реализует. После уточнения доменный скилл сам применяет свои правила записи ([ADR 0014](0014-confirmations.md)).

Если запрос относится к другому месту, скилл одной строкой предлагает правильный ход и выполняет его по «да», соблюдая [ADR 0012](0012-skill-composition.md). Короткая копия принципа доспроса находится в каждом `SKILL.md`, чтобы отдельно установленный скилл сохранял это поведение.
