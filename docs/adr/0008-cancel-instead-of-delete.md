# Разобранные идеи, справки и встречи отменяются

В SingularityApp MCP нет удаления. После переноса идеи, справки или встречи в своё место исходный Inbox item отменяется через `task_cancel`: он уходит из Inbox и остаётся восстановимым. Явная команда «перенёс, отмени» выполняется сразу с Read-back; одно «перенёс» не разрешает отмену — скилл одной строкой предлагает отменить и ждёт «да» ([ADR 0014](0014-confirmations.md)).

Встречу из Inbox `jedikit-tasks` передаёт `jedikit-calendar`. Исходный Inbox item отменяется только после успешного создания События и его Read-back; если создание или Read-back не подтверждены, Inbox item остаётся. Так перенос не теряет исходную запись до подтверждения результата у другого провайдера.
