# Разобранные идеи, справки и встречи отменяются

В SingularityApp MCP нет удаления. После того как пользователь перенёс идею, справку или встречу в своё место, исходный Inbox item отменяется (`task_cancel`) с подтверждением: он уходит из Inbox и остаётся восстановимым. Прежний сценарий с двумя подтверждениями и permanent delete был мёртвым кодом.
