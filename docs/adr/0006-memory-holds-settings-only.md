# В памяти агента только настройки

Native memory хранит timezone, рабочие дни, окна обзоров, режимы поддеревьев и ID выбранных привычек. Состояние обзоров не хранится: вчерашние хвосты daily open берёт из просроченных задач провайдера, дата следующего обзора эксперимента записана в его плане, пропущенный weekly не отслеживается — приглашает расписание. Хранение дат проведённых обзоров и восстановление по ним усложнили бы обзоры сильнее, чем дали пользы.
