# В памяти агента только настройки

Память Hermes хранит timezone, рабочие дни, окна обзоров, режимы поддеревьев, ID выбранных привычек и ID областей Habitify, выбранных как Ритуалы, и `habitId` первой привычки каждого Ритуала: API не хранит порядок, а время старта Ритуала — напоминание первой привычки. Настройки календаря: домашний часовой пояс IANA, календарь записи (по умолчанию `primary`), календари чтения (по умолчанию все видимые), границы дня и зазор между Бронью и Событием или Распорядком. Это настройки пользователя, не копия состояния провайдеров.

Состояние задач, привычек, Ритуалов, календаря и обзоров не хранится: вчерашние хвосты daily open берёт из просроченных задач провайдера, дата следующего обзора эксперимента записана в его плане, пропущенный weekly не отслеживается — приглашает расписание. План дня и выполнение Ритуала каждый раз читаются из провайдеров. Хранение дат проведённых обзоров и восстановление по ним усложнили бы обзоры сильнее, чем дали пользы. Представление Ритуала областью и ограничения его интерпретации описаны в [досье ритуалов](../../research/habits/rituals.md).

## Consequences

Настройки сохраняются только инструментом Hermes `memory` с `target="memory"`: одна компактная запись на скилл с префиксом `JediKit <скилл>:`. Новая запись — `add(content)`, изменение — `replace(old_text, content)`, который заменяет запись целиком. Отдельного чтения нет: текущие записи видны в контексте памяти. Лимит около 2200 символов общий для всех записей памяти профиля. Ответ `done:true` означает, что запись применена; `staged:true` с `pending_id` — что она ждёт одобрения (`/memory pending`) и не считается сохранённой.

Файлы скиллов JediKit — закреплённая ревизия пакета, а не хранилище пользователя; у владельца они лежат в неизменяемом Nix store. Поэтому настройки и состояние не записываются в `SKILL.md`, `references/` или файлы рядом — ни через `skill_manage`, ни файловыми инструментами, — даже если описание инструмента `memory` советует хранить предпочтения в скилле. Файлового fallback нет ([досье Hermes](../../research/platforms/hermes.md)).
