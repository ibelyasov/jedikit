# В памяти агента только настройки

Native memory хранит timezone, рабочие дни, окна обзоров, режимы поддеревьев и ID выбранных привычек. Состояние обзоров не хранится: вчерашние хвосты daily open берёт из просроченных задач провайдера, дата следующего обзора эксперимента записана в его плане, пропущенный weekly не отслеживается — приглашает расписание. Прежние пары `review_date` / `completed_at` и восстановление по ним усложняли обзоры сильнее, чем давали пользы.
