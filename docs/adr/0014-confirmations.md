# Подтверждение зависит от источника команды и потери данных

Полная явная команда пользователя выполняется сразу с Read-back после каждой записи. Явно названная группа записей выполняется последовательно без Preview, останавливается на первой ошибке и завершается отчётом applied/unapplied, без автоматического отката. Одиночное предложение агента формулируется одной строкой и выполняется после «да». Для набора изменений, собранного агентом, показывается один общий Preview и получается одно подтверждение, в том числе при двух провайдерах ([ADR 0012](0012-skill-composition.md)). Повторные согласования полной команды не улучшают её определённость; недостающие поля и неоднозначность разрешаются по [ADR 0013](0013-clarification.md).

В Habitify однострочное подтверждение всегда требуется для безвозвратной потери данных: удаления привычки, удаления области, удаления или отмены (`undo`) отметок. Остальные явные полные команды, включая перезапись заметки и смену даты обзора, выполняются сразу.

Удаление События Google Calendar по однозначной явной команде выполняется сразу. В отчёте указываются название, дата, время, календарь и то, что событие 30 дней находится в корзине Google, восстановить его можно только в интерфейсе Google. Защита календарной операции нужна при нескольких кандидатах и для выбора режима повторяющейся серии: только это вхождение, это и следующие, вся серия. Контракт провайдера — [досье Google Calendar](../../research/providers/google-calendar.md).

## Consequences

Кнопки подтверждения хоста относятся к конфигурации хоста, не скилла. Read-back — отдельное чтение результата у провайдера, ответ записи его не заменяет. При неопределённом исходе записи результат перечитывается, запись не повторяется вслепую. Safety-стопы сохраняются, фоновые запуски только читают ([ADR 0003](0003-no-unattended-writes.md)).
