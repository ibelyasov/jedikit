# Habitify через официальный REST API v2, а не через MCP

Официальный Habitify MCP (`mcp.habitify.me`) на 2026-10-05 даёт только отметки, статусы и список привычек за дату: создать привычку, изменить её, записать план в заметку или архивировать через него нельзя. Официальный REST API v2 (тариф Pro, ключ `X-API-Key`) покрывает всё это, и сам Habitify публикует agent skill поверх REST. Поэтому `jedikit-habits` работает только через REST v2: один контракт вместо двух. Ключ хранится в secret-окружении хоста (`HABITIFY_API_KEY`) и не попадает в репозиторий.

## Considered Options

- Только MCP: скилл не может создать привычку и хранить план.
- MCP для отметок + REST для остального: две авторизации и два контракта без выигрыша в возможностях.
- Привычки в SingularityApp: полный CRUD через MCP, но владелец пользуется Habitify.
