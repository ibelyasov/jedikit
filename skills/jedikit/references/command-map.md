# Карта команд JediKit

Команды и естественные фразы равноправны. `setup`, `status`, `help` уточняй именем скилла: они есть у нескольких владельцев. Эта карта объясняет возможности; выполнение, инструменты и правила операций определяет загруженный скилл-владелец.

## Задачи и проекты — `jedikit-tasks`

| Команда или запрос | Результат |
| --- | --- |
| `setup`, «настрой дерево» | Области, Папки, Проекты, рабочие дни, часовой пояс и Режимы поддеревьев |
| `capture`, «запиши», «сохрани, чтобы не забыть» | Исходная мысль во Inbox без классификации |
| `triage`, «разберём Inbox», «уточни задачу», изменение даты | Тип Inbox item, чистовая формулировка и место в дереве; Срок или Плановая дата |
| `project`, «проверь проект», «следующий шаг», «закрой проект» | Результат проекта, стартуемый Следующий шаг, судьба открытых задач |
| Разделы, теги, чек-лист, явное изменение состояния задачи | Пользовательская структура или указанное действие с задачей |
| `daily open`, «начнём день» | Вчерашние хвосты, Ресурс дня, Фокус-лист |
| `daily close`, «закроем день» | Остатки дня, затронутые проекты, Гвоздодёр |
| `weekly`, «еженедельный обзор» | Inbox, все проекты, следующие шаги и структура |
| «Пересмотрим когда-нибудь» | Ежемесячный пересмотр поддеревьев Когда-нибудь |
| «Накопился Inbox» | Отдельная сессия Inbox debt |
| Приглашение по расписанию хоста | Только чтение и приглашение к обзору |
| `status` | Доступность возможностей и настройки без чтения содержимого задач |
| `help` | Справка по задачам без обращения к аккаунту |

Встречу из Inbox с датой и временем ведёт `jedikit-calendar`; исходным Inbox item продолжает управлять `jedikit-tasks`. Идею и Справку пользователь переносит в собственное место. Kanban не поддерживается.

## Поведение и ритуалы — `jedikit-habits`

| Команда или запрос | Результат |
| --- | --- |
| `setup` | Настройки, существующие привычки, часовой пояс и окна обзоров |
| `design` | Одна гипотеза об одном поведении и План эксперимента |
| `log` | Отметка за дату или явно выбранная отмена |
| `urge` | Поддержка при Тяге по Плану эксперимента |
| `review` | Обзор эксперимента: оставить, изменить одну вещь, пауза или завершить |
| `adjust` | Изменение одной вещи в Плане эксперимента |
| `pause`, `archive` | Пауза или архив выбранной привычки |
| Явное удаление привычки или заметки | Запрошенное удаление по правилам владельца |
| `areas` | Группировка привычек по Областям Habitify |
| «Собрать ритуал» | Группа существующих привычек в Области Habitify, отмеченной в настройках как Ритуал |
| «Добавить звено» | Добавление привычки в Ритуал; новое поведение относится к проектированию эксперимента |
| «Убрать звено» | Снятие привычки с Области Ритуала без удаления привычки |
| «Время старта» | Напоминание первой привычки; связанный блок Распорядка меняется через `jedikit-calendar` |
| «Статус ритуала» | Сколько привычек отмечено и какие пропущены; «выполнен» — только если отмечены все |
| «Ритуал выполнен», «сделал утренний ритуал» | Отметки всех привычек Ритуала за дату |
| «Обзор ритуала» | Разбор Ритуала целиком |
| `status` | Выбранный эксперимент или запрошенный обзор привычек за день |
| `help` | Справка по привычкам без обращения к аккаунту |
| Time Off | Инструкция для приложения; команды `off` нет |

Порядок привычек Ритуала задаётся ручной сортировкой в приложении. Напоминания «после отметки A напомнить B» (`habitStacks`) — отдельная возможность только по просьбе. Сон как одно действие не является Ритуалом.

## Личный календарь — `jedikit-calendar`

| Команда или запрос | Результат |
| --- | --- |
| «Покажи день», «покажи завтра», «покажи неделю» | События, Брони и Распорядок; у дня — свободные окна и пересечения |
| «Создай Событие», «запиши встречу» | Обязательство с датой, временем и длительностью либо на весь день; возможен повтор |
| «Перенеси», «измени» | Изменение выбранного События; для серии различаются одно вхождение, это и следующие, вся серия |
| «Удали», «отмени Событие» | Удаление выбранного События или выбранной части серии |
| «Добавь Распорядок» | Регулярный блок поведения с устойчивым временем и длительностью по просьбе пользователя |
| `setup`, настройки из обычной фразы | Домашний часовой пояс, календарь записи, календари чтения, границы дня, зазор Броней |
| Календарная часть утренней сводки | Первое обязательное Событие, свободные окна, пересечения и Распорядок; только чтение |
| `status` | Настройки и доступность возможностей календаря |
| `help` | Справка по календарю |

Читаются выбранные личные календари Google, запись идёт в один выбранный календарь. Намерение без договорённости или встреча без даты — задача для `jedikit-tasks`. Привычка с реальной договорённостью по времени может иметь Событие; сама привычка остаётся в Habitify.

Поиск «когда у меня два часа?» отдельным сценарием не поддерживается — доступен вид дня. Рабочий Outlook, RSVP, приглашения, подготовка к встрече, follow-up и напоминания не входят. Скилл не настраивает расписание хоста.

## Вместимость и Брони — `jedikit-planning`

| Команда или запрос | Результат |
| --- | --- |
| «Спланируй день», «влезают ли дела» | Сквозной вид календаря и Фокус-листа, проверка вместимости, предложение выборочных Броней |
| «Забронируй 14–16 на отчёт» | Бронь под выбранную задачу |
| «Перепланируй день» | Перенос или снятие будущих Броней; при нехватке времени — предложение сдвинуть задачи |
| Утренняя сводка по расписанию владельца: часть про план дня | Календарная часть от `jedikit-calendar`, плюс Фокус-лист и вердикт вместимости; только чтение |
| `status` | Доступность скиллов, нужных инструментов и настроек без чтения содержимого аккаунтов |
| `help` | Команды, границы Плана дня и следующий шаг по запросу без обращения к аккаунтам |

Планируется только день. Распорядок и События не ужимаются ради задач. Прошедшая или пропущенная Бронь не закрывает задачу. Длительность берётся из `timeLength`, иначе даётся грубая оценка с «≈» без записи в задачу. Своего провайдера у скилла нет.

## Возможности и термины — `jedikit`

«Что умеет JediKit», «куда это записать», «какой скилл выбрать», «покажи все команды», «что такое Бронь» — справка по запросу без чтения аккаунтов и выполнения операций. Редкое глубокое уточнение намерения — внешний `grill-me` средствами хоста; это не шестой скилл JediKit.

## Как пройти день

1. `jedikit-tasks`: «Начнём день» — Daily open и Фокус-лист.
2. `jedikit-planning`: «Спланируй день» — вместимость и Брони.
3. `jedikit-tasks`: «Закроем день» — Daily close.
