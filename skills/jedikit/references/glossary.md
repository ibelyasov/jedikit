# Словарь JediKit

Определения объясняют слова человеческим языком. Правила операций с этими объектами — у скилла-владельца.

## Что куда относится

| Что у пользователя | Как называется | Чей скилл |
| --- | --- | --- |
| Договорённость с людьми на время: встреча, приём, занятие с тренером | Событие | `jedikit-calendar` |
| Дело без договорённости, мысль «не забыть» | Задача или Inbox item | `jedikit-tasks` |
| Многошаговое дело с результатом | Проект | `jedikit-tasks` |
| Идея, справочный материал | Inbox item; пользователь переносит его в своё место | `jedikit-tasks` |
| Поведение, которое хочется проверить или закрепить | Эксперимент на привычке | `jedikit-habits` |
| Несколько привычек подряд в определённое время дня | Ритуал | `jedikit-habits` |
| Регулярный блок с устойчивым временем на ленте дня: Ритуал целиком, сон | Распорядок, только по просьбе | `jedikit-calendar` |
| Время сегодня под конкретную задачу | Бронь | `jedikit-planning` |

В календарь попадает то, что занимает определённый промежуток в определённый момент и должно быть видно на ленте дня: Событие, Бронь, Распорядок. Отдельные привычки внутри Ритуала и привычки без устойчивого времени туда не попадают. «Плавание с тренером во вторник в 19:00» — Событие по договорённости; сама привычка плавать остаётся в Habitify.

## Календарь и План дня

| Термин | Объяснение |
| --- | --- |
| Событие | Обязательство в календаре со временем: встреча, приём, договорённость. Намерение без договорённости — задача. |
| Бронь | Время в календаре под задачу. Это ссылка, а не копия: срок, состояние и выполнение остаются в SingularityApp. Прошедшая Бронь ничего не закрывает. |
| Распорядок | Роль события в календаре: регулярный блок поведения с устойчивым временем и длительностью. Ставится только по просьбе. Не путать с Режимом поддерева. |
| План дня | Фокус-лист, разложенный по окнам календаря, с проверкой вместимости и Бронями. Только на один день. |
| Свободное окно | Промежуток без Событий, Броней и Распорядка внутри границ дня из настроек. |

## Задачи — SingularityApp

| Термин | Объяснение |
| --- | --- |
| Область | Проект верхнего уровня, задающий контекст жизни: Работа, Личное или выбранный пользователем. |
| Папка | Проект с дочерними проектами. Может содержать одиночные задачи; своего результата и Следующего шага не требует. |
| Проект | Проект без дочерних проектов: многошаговое дело с результатом и стартуемым Следующим шагом. |
| Режим поддерева | Наследуемый признак Области или Папки: рабочие дни, личные дни, всегда или когда-нибудь. |
| Когда-нибудь | Режим поддерева: проекты не попадают в Daily open, не требуют Следующего шага и пересматриваются ежемесячно. |
| Задача | Одно физическое действие: глагол, объект и видимый признак готовности. |
| Следующий шаг | Задача проекта, которую можно начать сейчас; обычно одна, две — если независимы и параллельны. |
| Раздел | Блок задач внутри проекта, когда у длинного проекта видны реальные части. |
| Тег | Пользовательский признак для повторяющегося выбора между задачами разных проектов. |
| Чек-лист | Список-памятка внутри одной задачи, а не план шагов. |
| Inbox item | Сырая, ещё не разобранная запись во входящих. |
| Capture | Немедленная запись исходной мысли во Inbox без классификации. |
| Triage | Разбор одного Inbox item: тип, чистовая формулировка, место в дереве. |
| Идея / Справка / Встреча | Inbox item, который не задача и не проект. Идею и Справку пользователь переносит в своё место; Встреча с договорённостью и временем становится Событием. |
| Срок | Внешний жёсткий срок (`deadline`), после которого наступают последствия. |
| Плановая дата | Дата, которую пользователь выбрал, чтобы начать задачу (`start`); не Срок. |

## Обзоры

| Термин | Объяснение |
| --- | --- |
| Daily open | Утренний обзор: вчерашние хвосты, Ресурс дня, Фокус-лист. Следом — План дня. |
| Ресурс дня | Самооценка «низкий / обычный / высокий» для размера Фокус-листа, а не измерение. |
| Фокус-лист | Выбранные на сегодня задачи, без проверки календаря и вместимости; её делает План дня. |
| Daily close | Вечерний обзор: остатки дня, затронутые проекты, Гвоздодёр. |
| Гвоздодёр | Обратная прокрутка прошедшего дня, чтобы вытащить незаписанные обязательства. |
| Weekly | Еженедельный обзор Inbox, всех проектов, Следующих шагов и структуры. |
| Inbox debt | Накопившиеся неразобранные Inbox items, разбираемые отдельными сессиями по 15, 10 или 5 минут. |

## Привычки — Habitify

| Термин | Объяснение |
| --- | --- |
| Область Habitify | Группа привычек; не то же, что Область в SingularityApp. Может быть отмечена как Ритуал. |
| Ритуал | Группа привычек, выполняемых подряд в определённое время дня; в Habitify — Область, отмеченная в настройках как Ритуал. Время старта — напоминание первой привычки; порядок задаётся ручной сортировкой в приложении; длительности в Habitify нет. Сон — одно действие, а не Ритуал. |
| Эксперимент | Проверка одной гипотезы об одном наблюдаемом поведении, привязанная к привычке. |
| План эксперимента | Текст в заметке привычки: цель, поведение, триггер, минимальное действие или замена, if–then, дата обзора, Stop-rule. |
| Отметка | Запись о выполнении, срыве, пропуске или количестве за дату. |
| Тяга | Момент сильного желания сорваться; скилл предлагает 1–3 действия из плана. Не диагноз. |
| Обзор эксперимента | Разбор по плану: оставить, изменить одну вещь, пауза или завершить. |
| Поддержание | Эксперимент, ставший привычным; обзор раз в месяц. |
| Stop-rule | Заранее оговорённое условие остановки эксперимента. |
| Safety-стоп | Остановка коучинга при признаках клинического риска с направлением к специалисту. |

## Записи и хост

Эти слова встречаются в отчётах скиллов.

| Термин | Объяснение |
| --- | --- |
| Preview | Точный список изменений, собранных агентом, до одного подтверждения. Одиночное предложение агента — одна строка и «да». |
| Группа операций | Две и более записи подряд со стопом на первой ошибке. Названные пользователем — сразу; собранные агентом — после одного Preview. |
| Read-back | Чтение записанного обратно у провайдера после каждой записи; ответ на запись его не заменяет. |
| applied / unverified / unapplied | Подтверждено Read-back / могло состояться, но не подтверждено / не выполнено. |
| Инструменты хоста | Операции провайдера, которые хост даёт агенту; подключение и авторизация принадлежат хосту. |
| Контракт инструментов | Декларативный `tools.json` провайдерного скилла: какие операции он ожидает от хоста. Не настройка подключения. |
| Адаптер хоста | Доверенный компонент хоста с операциями Habitify; ключ остаётся у адаптера. |
| Native memory | Встроенная память хоста; JediKit хранит в ней только настройки, а не задачи, Отметки или проведённые обзоры. |
