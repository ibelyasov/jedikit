# Обзор эксперимента, pause и archive

Операции выполняй по [operation-policy.md](operation-policy.md).

## Review

1. Возьми выбранный `habitId`, план и дату обзора по [rest-api.md](rest-api.md). Прочитай адресную статистику за согласованный период. Если план недоступен, попроси его текст у пользователя; не достраивай критерий срыва или stop-rule из названия.
2. Перед чувствительным коучингом проведи скрининг по [safety.md](safety.md). Прочитай [coaching.md](coaching.md), [habit-method.md](habit-method.md) и нужную доменную справку.
3. Сравни наблюдения с поведением и возможностями его выполнить: что происходило, в каком контексте, насколько выполнимо минимальное действие. Отдельно спроси о нагрузке и нежелательных эффектах.
4. Отдели факты от объяснений и внешних результатов. При нехватке данных предложи продолжить наблюдение, а не объявляй успех или срыв. Один удачный период не доказывает причинность или автоматичность.
5. Предложи выбор: оставить план, изменить одну вещь, пауза или завершить. При срабатывании stop-rule останови эксперимент; при клиническом риске примени Safety-стоп, не усиливай коучинг.
6. Для активного эксперимента предложи следующую дату через неделю; для поддержания — через месяц. Это продуктовый default, который пользователь может изменить. Дату следующего обзора включи в план, не в память.
7. Размести согласованную следующую дату в плане способом из rest-api.md. Для работы с памятью используй [setup.md](setup.md).

Если обзор прерван, продолжи с доступным планом и наблюдениями в следующем разговоре. Несколько выбранных экспериментов разбирай по одному.

## Pause

Уточни выбранную привычку и условия возврата к разговору. Примени ветку pause из rest-api.md.

## Archive

Для выбранной привычки используй REST archive и чтение результата из rest-api.md.

Не считай stop-rule, завершение обзора или нехватку отметок выбором архива. Для неоднозначного «завершить» рекомендуй трактовку «архивировать выбранную привычку с сохранением истории» по общей политике. Не подменяй запрос удаления архивом: уточни желаемую судьбу истории; если требуется именно удаление, направь пользователя в приложение.
