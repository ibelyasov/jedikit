# Log и urge

Операции выполняй по [operation-policy.md](operation-policy.md).

## Одна отметка

1. Для запроса вроде «Отметь медитацию» найди выбранную привычку по разделу «Поиск привычки по названию» в [habitify-tools.md](habitify-tools.md). Определи дату в timezone пользователя и вид отметки: выполнение, срыв, пропуск или количество. Не отмечай другие привычки по сходству названий.
2. Прочитай выбранную привычку и исходные данные этой даты по [habitify-tools.md](habitify-tools.md). Для количества сохрани исходную сумму в текущем разговоре, не в памяти. Не приравнивай отсутствие записи к нулю или срыву.
3. Сопоставь событие с критерием плана. Для сокращения или отказа различай событие нежелательного поведения и выполнение безопасной замены. Не записывай `completed` только потому, что пользователь назвал нежелательный эпизод «выполненным».
4. Выбери адресную запись и способ чтения результата по habitify-tools.md.

`add-habit-log` добавляет новую отметку к количеству за дату, а не заменяет дневную сумму. Сравни Read-back с исходной суммой и запрошенным добавлением; если исходная сумма неизвестна, назови предел проверки. Не используй `complete-habit` вместо явно названного количества.

Для единиц и смысла количества используй habitify-tools.md; для интерпретации наблюдений — [habit-method.md](habit-method.md).

## Отмена

Определи, какая отмена запрошена, и примени область действия из habitify-tools.md.

`undo-habit-logs` удаляет **все** отметки одной выбранной привычки за выбранную дату и сбрасывает статус. Перед ним адресно прочитай статистику даты и установи текущий `totalLog`; неизвестная сумма или отсутствующий элемент не означают ноль. Если сумму нельзя подтвердить, останови запись и предложи очистить выбранную дату в приложении.

Всегда покажи Preview с привычкой, датой, текущим `totalLog` и буквальной фразой «будут удалены все отметки за D», заменив D календарной датой. Дождись подтверждения, кроме случая, когда пользователь уже буквально попросил удалить все отметки этой привычки за этот день или очистить этот день: тогда покажи тот же Preview и выполни явную одиночную команду без второго согласия. Запрос «отмени последнюю отметку» или «отмени отметку» не разрешает дневной undo, даже если сумма выглядит как одна запись. Для группы операций сохраняется общее подтверждение operation-policy.md.

`delete-habit-log` удаляет конкретную отметку только по известному `logId`. Установи принадлежность ID выбранной привычке по достоверному контексту его получения и сверь дату, если она доступна; при неоднозначной принадлежности остановись. Read tools не возвращают `logId`, поэтому не требуй получить его через эти чтения; если достоверного ID нет, предложи отмену конкретной отметки в приложении. Не угадывай ID, не считай дневную сумму одной отметкой и не создавай отрицательное количество как компенсацию.

Исправление может потребовать очистки даты и новой записи; рассматривай их как две отдельные операции, а не подмену отмены противоположным статусом.

## Тяга

Прочитай доступный план и [cessation.md](cessation.md). При признаках риска следуй [safety.md](safety.md). Если плана нет, предложи только безопасную разговорную поддержку без утверждения, что действует согласованный эксперимент.

Выбери 1–3 коротких действия из плана: выйти из ситуации с сигналом, сделать минимальную замену, переключиться на заранее выбранное безопасное действие. Дай пользователю выбрать доступное сейчас. Не обещай, что тяга исчезнет за заданное время.

Если в запросе есть также log, используй раздел «Одна отметка» этой справки.
