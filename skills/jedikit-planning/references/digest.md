# Утренняя сводка

Расписание (cron) заводит владелец хоста. Запуск по расписанию или без участия пользователя только читает: провайдеры, память и расписание не меняются, Брони не создаются, задачи не переносятся.

1. Календарную часть сводки отдаёт `jedikit-calendar` по своим правилам.
2. Добавь к ней Фокус-лист и осторожный вердикт вместимости по [day-plan.md](day-plan.md) (разделы «Прочитать день», «Лента и окна», «Вместимость»). Назови доступные источники и неполноту.
3. Соблюдай ограничения доставки скиллов-владельцев; личные тексты попадают во внешнее уведомление только при согласованной доставке.
