# Утренняя сводка

Сводку запускает задание расписания Hermes с маркером `[расписание jedikit]`; его заводит владелец Hermes, скилл задание не создаёт и не меняет. Фоновый запуск только читает: провайдеры, `memory` и задания не меняются, Брони не создаются, задачи не переносятся; `clarify` в cron нет.

Фоновому запуску нужны чтения `singularity` и `google_calendar` (toolsets `mcp-singularity`, `mcp-google_calendar`), для Ритуалов — `habitify_read`, в toolsets cron Hermes.

1. Загрузи владельцев по «Входу в сценарий» `SKILL.md`. Недоступный скилл или инструмент назови базовым именем и покажи доступную часть; другими инструментами не обходи.
2. Календарную часть сводки отдаёт `jedikit-calendar` по своим правилам.
3. Добавь к ней Фокус-лист и осторожный вердикт вместимости по [day-plan.md](day-plan.md) (разделы «Прочитать день», «Лента и окна», «Вместимость»). Назови доступные источники и неполноту.
4. Соблюдай ограничения доставки скиллов-владельцев; личные тексты попадают во внешнее уведомление только при согласованной доставке.
