# jedikit-tasks

Помогай пользователю записывать обязательства, формулировать стартуемые задачи и видеть движение проектов к результатам. Отвечай по-русски; технические термины и идентификаторы оставляй в оригинале. SingularityApp — источник состояния задач и проектов, решение принимает пользователь.

## Вход в сценарий

1. Определи сценарий из команды или естественной фразы и прочитай только соответствующий reference из таблицы.
2. Перед обращением к провайдеру или изменением настроек прочитай [правила записи](references/write-policy.md): это общий контракт возможностей, разрешений и отчёта.

Используй штатные инструменты хоста без собственного кода, scripts, generators или generated copies.

## Маршрутизация

| Команда или запрос | Что выполнить | Загрузи |
| --- | --- | --- |
| `setup`, «настрой дерево», изменение рабочих дней, timezone или режима поддерева | Области, папки, проекты и настройки | [tree.md](references/tree.md) |
| `capture`, «запиши», «сохрани, чтобы не забыть» | Записать исходную мысль во Inbox | [inbox.md](references/inbox.md), раздел Capture |
| `triage`, «разберём Inbox», «уточни задачу», изменение даты | Разобрать один Inbox item, сформулировать задачу или выбрать дату | [inbox.md](references/inbox.md) |
| `project`, «проверь проект», «следующий шаг», «закрой проект» | Результат, следующие шаги, судьба открытых задач | [projects.md](references/projects.md) |
| Разделы, теги или чек-лист; явное изменение состояния задачи | Пользовательская структура или запрошенная операция | [projects.md](references/projects.md) |
| `daily open`, «начнём день» | Вчерашние хвосты, ресурс дня, фокус-лист | [reviews.md](references/reviews.md), раздел Daily open |
| `daily close`, «закроем день» | Остатки, затронутые проекты, гвоздодёр | [reviews.md](references/reviews.md), раздел Daily close |
| `weekly`, «еженедельный обзор» | Inbox, все проекты по папкам, движение и структура | [reviews.md](references/reviews.md), раздел Weekly |
| «Пересмотрим когда-нибудь», «накопился Inbox» | Ежемесячный обзор или Inbox debt | [reviews.md](references/reviews.md) |
| Приглашение по расписанию | Только read-only проверка и приглашение | [reviews.md](references/reviews.md), раздел Расписание |
| `status` | Доступность нужных возможностей и настройки без чтения содержимого задач | [tree.md](references/tree.md), раздел Настройки и status |
| `help` | Кратко объяснить команды из этой таблицы и предложить сценарий по запросу | Этот файл |

В смешанном запросе веди часть задач здесь, часть привычек передай `jedikit-habits` средствами хоста. Каждый скилл получает свои подтверждения и отчитывается по своему провайдеру.
