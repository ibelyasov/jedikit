# Настройки и status

## Что хранится

В `memory` храни только настройки:

- timezone;
- выбранные рабочие дни;
- окна Daily open, Daily close, Weekly и месячного обзора Когда-нибудь;
- явно выбранные Режимы поддерева с ID Областей или Папок.

Не храни пометки Папок, копии дерева или задач, Фокус-листы, остатки и состояние обзоров. Тип объекта определяй по [дереву](tree.md). Если сохранённый ID исчез или перестал быть Областью или Папкой, уточни привязку; по похожему названию не заменяй.

## Где хранить настройки

- Только инструмент `memory` с `target="memory"`: одна компактная запись этого скилла, начинающаяся с `JediKit tasks:`. Отдельного чтения нет: текущие записи видны в контексте памяти.
- Записи с этим префиксом нет — `action="add"`, `content`. Есть — `action="replace"`, `old_text` (уникальный фрагмент этой записи) и `content` с полной новой записью: replace заменяет запись целиком, поэтому перенеси в неё все сохраняемые значения. Вторую запись не создавай, `target="user"` не используй.
- `done: true` — запись применена; это Read-back настроек. `staged: true` с `pending_id` — запись ждёт одобрения: скажи «Сохранение ждёт подтверждения памяти: `/memory pending`» и не называй настройку сохранённой. Отказ, например по лимиту, — `unapplied`; ответ без `done` и `staged` — `unverified`.
- Лимит около 2 200 символов на все записи памяти профиля: храни только выбранные значения и ID, остальное перечитывай у провайдера. При отказе по лимиту сообщи об этом; чужие записи не сокращай.
- Файлы скиллов JediKit (`SKILL.md`, `references/`, `tools.json`) только для чтения: не вызывай `skill_manage`, не создавай файлов настроек и не обходи `memory` другим способом, даже если подсказка Hermes советует хранить предпочтения в скилле.
- Если `memory` недоступен, настройки действуют только в текущем разговоре; сохранение не обещай.

## Изменение

Обычная фраза меняет настройку без особой команды: «теперь рабочие дни со вторника по субботу», «пусть Личное будет всегда». Прочитай текущую настройку, разреши ID объекта и запиши по [правилам записи](write-policy.md).

Если `memory` недоступен или сохранение не подтверждено, используй явно выбранные настройки текущего диалога, назови это ограниченным setup и не обещай сохранение между сессиями. Не заменяй память служебной задачей, проектом, Тегом или файлом.

Приглашения через `cronjob_manage` — по [schedule.md](schedule.md).
