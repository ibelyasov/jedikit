# Проекты

Тип объекта и наследуемый режим — по [дереву](tree.md). Формулировку и состояние Задач — по [tasks.md](tasks.md).

## Осмотр

1. Прочитай объект через `project_get`, дерево через `project_list`, открытые Задачи через `task_list`.
2. Покажи результат Проекта, открытые Задачи, препятствия и Следующий шаг. Если запрос нельзя выполнить без неизвестного результата, включи его в блокирующие пробелы. Число выполненных Задач не доказывает достижение результата.
3. Активному Проекту нужен стартуемый Следующий шаг. Используй выбранный; если его нет, предложи один, два — если они независимы и параллельны. Полный будущий план не придумывай.
4. Существующую Задачу переиспользуй через `task_update` или `task_move`, новую создавай через `task_create`. Копии Задач ради организации не создавай.

## Создание и изменение

1. Многошаговому делу нужны результат, место в дереве и Следующий шаг; используй заданные.
2. Создай через `project_create` или измени через `project_update`; `project_get`/`project_list` читай только для выбора объекта и родителя. Поля родителя и заметки передавай лишь при их изменении.
3. Результат записывай в заметку, сохраняя прежний текст.
4. Preview набора, собранного агентом, показывает родителя, название, результат и точные изменения Задач.
5. Создай или измени Проект, затем выполни операции над Задачами с полученными ID.

## Закрытие или отказ

1. Прочитай Проект, его открытые Задачи и дочерние проекты. Для Папки нужны решения по всему затронутому дереву.
2. При завершении проверь результат. При отказе причину не требуй; записывай её в заметку через `project_update`, только если пользователь выбрал её сохранить, сохраняя прежний текст.
3. По каждой открытой Задаче нужно решение: завершить выполненную, перенести нужную, отменить ненужную или явно оставить открытой в архиве. Используй выбранные `task_complete`, `task_cancel`, `task_move`, `task_update`. Список молча не отменяй.
4. Установи охват `project_archive`: потомки, открытые и повторяющиеся Задачи. Если последствия неизвестны, предложи ручную операцию в приложении.
5. Preview набора, собранного агентом, показывает изменение заметки, судьбу каждой Задачи и последствия архива.
6. Выполни изменения заметки и Задач, `project_archive` — последним.

Возврат из архива — `project_unarchive` с установленным охватом. Восстановление прежних состояний и повторений не обещай; их изменения, если пользователь их явно не назвал, предлагай отдельно.
