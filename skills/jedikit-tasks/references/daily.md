# Daily open и Daily close

## Общие правила

- Прочитай нужные настройки по [settings.md](settings.md) и Режимы поддерева по [дереву](tree.md); режим по умолчанию не задавай.
- Правила включения режимов применяй к каждому кандидату, хвосту, остатку и затронутому Проекту по дню обзора; Срок их не отменяет.
- Фиксированного предела Фокус-листа нет. Календарь не читай и вместимость не обещай; скажи: «Календарь и доступное время не проверены».
- Даты, длительность и приоритет — по [tasks.md](tasks.md); результат, состояние и Следующий шаг — по [осмотру Проекта](projects.md#осмотр).

## Daily open

1. Определи сегодня в timezone пользователя. Прочитай вчерашние хвосты через `task_list_overdue`, затем Today через `task_list_today`; оставь подходящие по режимам.
2. Ресурс дня возьми, если назван; иначе спроси: `низкий / обычный / высокий`. По самооценке предложи более короткий или широкий Фокус-лист; ресурс из числа Задач не вычисляй.
3. Если нужны другие кандидаты, прочитай открытые Задачи подходящих поддеревьев через `task_list` и Проекты через `project_get`. Всё дерево без необходимости не обходи.
4. С пользователем выбери стартуемые Задачи; при трудном старте — [tasks.md](tasks.md#трудный-старт).
5. Выбранным предложи `start` = сегодня. По каждому не выбранному хвосту и Задаче Today в допустимых режимах получи решение: оставить, снять Плановую дату, назначить дату пользователя или отменить после отказа (`task_update`, `task_move`, `task_cancel`). «Оставить» записи не требует.
6. Preview набора, собранного агентом: выбранные Задачи с `start` = сегодня и решения по остальным. Выполни разрешённое и покажи Фокус-лист.

## Daily close

1. Назови день обзора. Прочитай остатки через `task_list_today`, `task_list_overdue`, при необходимости `task_list`; оставь подходящие по режимам. Today не исторический снимок: для другого дня недостающее спроси у пользователя.
2. По каждому остатку нужно решение: оставить, снять Плановую дату, перенести на дату пользователя, завершить выполненное или отменить после отказа (`task_update`, `task_complete`, `task_cancel`).
3. Затронутые Проекты возьми из диалога и доступных изменений Задач. Фильтр изменений `task_list` используй, только если он есть; при неполной истории спроси, какие Проекты затронуты.
4. Прочитай подходящие по режимам Проекты через `project_get` и дерево через `project_list`; проведи [осмотр](projects.md#осмотр).
5. Гвоздодёр: попроси прокрутить день назад от вечера к утру — места, разговоры, сообщения, переключения — и назвать незаписанные мысли и обязательства.
6. Названную мысль записывай по [Capture](inbox.md#capture) только по явной просьбе либо включи как предложение в общий набор; автоматически не записывай.
7. Preview набора, собранного агентом, объединяет изменения остатков, Проектов и ещё не записанные Capture. Уже выполненные явные команды не повторяй. Выполни разрешённое и сообщи результат.
