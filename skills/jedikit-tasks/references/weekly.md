# Weekly

1. Прочитай Inbox через `task_list_inbox` и разбирай Inbox items по одному по [Triage](inbox.md#triage). Большой остаток вынеси в отдельные сессии [Inbox debt](inbox.md#inbox-debt); неразобранные записи обработанными не объявляй.
2. Прочитай всё доступное дерево через `project_list` и пройди все Области и Папки вместе с их одиночными Задачами, а не только затронутые Проекты.
3. Для каждого активного Проекта прочитай `project_get` и открытые Задачи через `task_list`, проведи [осмотр](projects.md#осмотр) и сравни движение к результату.
4. Перечисли поддеревья Когда-нибудь и окно месячного обзора, если оно есть в настройках. В выбор недели их не включай; все они проверяются на [месячном обзоре](someday.md).
5. Проверь актуальность открытых Задач и известных Сроков, включая просроченные через `task_list_overdue`. Обязательной недельной квоты нет.
6. Подготовь предложения по Разделам и Тегам по [structure.md](structure.md).
7. Изменения по итогам обхода собери в один Preview; Triage остаётся разбором по одному, выбранный набор веди без вопроса о продолжении. Уже выполненное не повторяй.
8. Сообщи охват, оставшиеся решения и ограничения.
