# Расписание

Приглашения к Daily open, Daily close, Weekly и месячному обзору Когда-нибудь — задания `cronjob_manage` Hermes. Если инструмента нет, объясни ограничение.

## Настройка приглашения

1. Создавай задание только по явной просьбе пользователя или после его «Да» на предложение; запись идёт по [правилам записи](write-policy.md#разрешение), в Preview параметры входят целиком.
2. Вызов: `cronjob_manage(action="create", schedule=…, prompt=…, skills=[…])`.
   - `schedule` — cron-выражение, например `0 18 * * 1`, или интервал вида `every 2h`. Поля timezone нет: время считается в timezone профиля Hermes. Если пояс пользователя из настроек может отличаться, скажи это в Preview.
   - `prompt` начинай маркером `[расписание jedikit]`, затем направляй к чтению и приглашению открыть нужный обзор.
   - `skills` — имя этого скилла так, как оно загружено (голое `jedikit-tasks` или с префиксом `agent-plugin-…:`).
   - `deliver` не задавай, кроме места, явно названного пользователем; по умолчанию доставка идёт в чат, где создано задание.
   - `enabled_toolsets` не задавай.
3. Read-back: `cronjob_manage(action="list")`, найди задание по ID и сверь расписание, текст, скиллы и доставку. Задание, его запуск и доставка — разные результаты: список подтверждает только задание.
4. Фоновому запуску нужно чтение `singularity` (toolset `mcp-singularity`) в toolsets cron Hermes; из чата это не проверить. Скажи об этом при создании: без него запуск назовёт недостающее и покажет только доступное. Ограничение не обходи.

## Фоновый запуск

1. Запуск с маркером только читает и приглашает по [правилу фонового запуска](write-policy.md#разрешение). В cron нет `clarify`: вопросы и предложения оставь до следующего разговора.
2. Если нужных инструментов SingularityApp нет, назови недостающие и покажи только доступное; другие инструменты вместо них не используй.
3. Во внешнем уведомлении показывай только количества и короткое приглашение. Названия Задач и Проектов добавляй лишь после отдельного согласия на такую доставку; тексты и заметки без него не включай.
4. При ошибке подключения сообщи безопасную ошибку без секретов.
5. Weekly пропущенным не объявляй: приглашение не показывает, состоялся ли обзор.
