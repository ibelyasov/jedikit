# Расписание

Приглашения к Daily open, Daily close, Weekly и месячному обзору Когда-нибудь ставит планировщик хоста. Если его нет, объясни ограничение.

## Настройка приглашения

1. Установи timezone, частоту, окно, место доставки и точный текст задания. Запись в планировщик идёт по [правилам записи](write-policy.md#разрешение); в Preview эти параметры входят целиком.
2. Текст задания начинай с маркера `[расписание jedikit]`, затем направляй к чтению и приглашению открыть нужный обзор.

## Фоновый запуск

1. Запуск с маркером только читает и приглашает по [правилу фонового запуска](write-policy.md#разрешение).
2. Во внешнем уведомлении показывай только количества и короткое приглашение. Названия Задач и Проектов добавляй лишь после отдельного согласия на такую доставку; тексты и заметки без него не включай.
3. При ошибке подключения сообщи безопасную ошибку без секретов.
4. Weekly пропущенным не объявляй: приглашение не показывает, состоялся ли обзор.
