# Распорядок

Распорядок — регулярный блок поведения с устойчивым временем и длительностью: ритуал целиком или одно действие, например сон. Ритуал — группа привычек подряд, представленная Областью Habitify; сон сам по себе не ритуал. Создавай Распорядок только по просьбе пользователя, не предлагай добавить сон или другие блоки самостоятельно.

## Создать или изменить

1. Собери название, начальную дату, время, длительность/окончание и правило повторения. Используй известное; все блокирующие пробелы спроси одним сообщением. Длительность ритуала в Habitify отсутствует, не выводи её из числа привычек.
2. Создай повторяющееся событие в календаре записи по [events.md](events.md) и [operation-policy.md](operation-policy.md). В описание добавь ровно одну видимую строку роли, сохранив названный пользователем текст:
   - `JediKit · Распорядок · ритуал: <название области Habitify>`;
   - `JediKit · Распорядок · <действие>` для одиночного регулярного действия.
3. Устанавливай `recurrence` по просьбе, `sendUpdates: "none"`; без `extendedProperties`, участников и автоматических буферов. Не создавай отдельные календарные записи для каждой привычки внутри ритуала или привычек без устойчивого времени.
4. После записи перечитай событие: время, длительность, повтор, календарь и строка роли должны совпадать. Результат сообщи с датой, поясом и режимом серии. Если Read-back не подтверждает поля, остановись с `unverified`.

Для изменения/удаления уже существующего Распорядка применяй выбор объекта, режимы серии и проверку результата из events.md. Явная полная команда — сразу; предложение агента — одна строка и «да», собранный агентом набор — один Preview. Это правило не разрешает самостоятельно предлагать сократить или сдвинуть Распорядок, чтобы уместить другие дела: скажи, что день не помещается.

## Передача времени ритуала

`jedikit-habits` может явно передать изменение времени существующего блока вместе со сменой напоминания первой привычки. Используй уже переданные название Области, время, дату и режим серии; недостающее уточни. Загрузи свои правила и измени только соответствующий блок календаря записи. Верни точный `applied`/`unverified`/`unapplied`, чтобы вызывающий скилл продолжил последовательную группу или остановился на ошибке. Подтверждённый общий набор не требует второго Preview для календарной части.

Если из переданных или доступных в текущем контексте данных известно, что время блока расходится с напоминанием первой привычки ритуала в Habitify, сообщи оба времени и расхождение, ничего автоматически не исправляй. Без времени напоминания не утверждай, что они совпадают; объясни, что сопоставление не выполнено. Не меняй напоминание и не считай календарный блок источником состояния Habitify.

Распорядок виден на ленте, но его прохождение не означает выполнения привычек. Отметки и состав ритуала остаются у `jedikit-habits`, состояние задач — у `jedikit-tasks`.
