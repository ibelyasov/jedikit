# Отложенные возможности

Согласованный scope пересборки — [#1](https://github.com/ibelyasov/jedikit/issues/1), словарь — [CONTEXT.md](CONTEXT.md), решения — [docs/adr/](docs/adr/). Этот список не обещает релиз: расширение требует отдельного исследования и согласования.

## Идеи

- Отдельный обзор и инкубатор идей, периодичность и решения `оставить / дешёвый тест / задача / проект / убрать`.
- Сейчас Triage распознаёт идею, справку или встречу и предлагает ручной перенос в пользовательское место. После переноса исходный Inbox item отменяется через `task_cancel` с подтверждением; permanent delete не нужен (ADR 0008).

## Ожидание и делегирование

- Семантика ожидания, последующего запроса и владельца результата.
- Чужая работа не становится личной задачей автоматически; сообщения другим людям требуют разрешения. Служебная папка для ожидания не создаётся без решения пользователя.

## Напоминания и календарь

- Отдельный контракт напоминаний: плановая дата `start`, срок `deadline`, встреча и уведомление расписания хоста различаются.
- Подтверждённый канал доставки и настройки приватности для напоминаний.
- Подключение календаря для проверки вместимости. Текущий Фокус-лист не является расписанием и не проверяет календарь.

## Расширенное планирование проектов

- Зависимости, этапы, несколько проектов одновременно и оценка движения к результатам.
- Текущий скилл ведёт результат, полезный контекст и следующий шаг, делает Weekly и закрывает проект через судьбу открытых задач и архив.

## Публикация и интеграции

- Подача в marketplaces Claude Code/Codex и Hermes Hub после отдельного решения о публикации.
- События и webhooks — только при подтверждённом контракте провайдера. Собственный poller не входит в scope (ADR 0004).
- Отдельный скилл-маршрутизатор не согласован: смешанный запрос сейчас разбирается каждым из двух скиллов в своей части.

## Явно исключено текущими решениями

- Kanban и toolset `kanban` (ADR 0007).
- Команда `off`: Off Mode отсутствует в API Habitify, включается только вручную в приложении. Это не то же самое, что `pause`.
- Память состояния обзоров, технических дат выполнения и поведенческих паттернов: native memory хранит только настройки по ADR 0006.
- MCP Habitify и REST fallback: Habitify использует только официальный REST API v2 как основной контракт (ADR 0001); SingularityApp использует официальный MCP без REST.
- Собственный код, production MCP/proxy/runtime, generated copies, служебные проекты/теги, telemetry, self-update и scheduled installation.
- Серверный batch: группа операций выполняется последовательно после одного подтверждения, останавливается на первой ошибке и не откатывается автоматически.
- Permanent delete исходного Inbox item и фоновая запись без подтверждения (ADR 0003, 0008).
- Публичный SLA поддержки.
