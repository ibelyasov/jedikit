# Отложенные возможности

Направления, которые могут появиться позже. Список не обещает релиз: каждое расширение требует отдельного исследования и согласования. Текущие решения — в [CONTEXT.md](CONTEXT.md) и [docs/adr/](docs/adr/).

## Идеи

- Отдельный обзор и инкубатор идей: периодичность и решения `оставить / дешёвый тест / задача / проект / убрать`. Сейчас Triage предлагает перенести идею в место, выбранное пользователем ([ADR 0008](docs/adr/0008-cancel-instead-of-delete.md)).

## Ожидание и делегирование

- Семантика ожидания, последующего запроса и владельца результата.
- Чужая работа не становится личной задачей автоматически; сообщения другим людям требуют разрешения. Служебная папка для ожидания не создаётся без решения пользователя.

## Напоминания и календарь

- Отдельный контракт напоминаний, различающий плановую дату `start`, срок `deadline`, встречу и уведомление расписания хоста.
- Подтверждённый канал доставки и настройки приватности для напоминаний.
- Подключение календаря для проверки вместимости Фокус-листа.

## Расширенное планирование проектов

- Зависимости, этапы, несколько проектов одновременно и оценка движения к результатам.

## Публикация и интеграции

- Подача в marketplaces Claude Code, Codex и Hermes Hub после отдельного решения о публикации.
- События и webhooks — только при подтверждённом контракте провайдера; собственный poller не входит в scope ([ADR 0004](docs/adr/0004-no-custom-code.md)).
- Отдельный скилл-маршрутизатор: сейчас смешанный запрос каждый из двух скиллов разбирает в своей части.

## Явно исключено

- Kanban и toolset `kanban` ([ADR 0007](docs/adr/0007-no-kanban.md)).
- Команда `off`: Off Mode отсутствует в API Habitify и включается только в приложении. Это не то же самое, что `pause`.
- Память состояния обзоров, дат выполнения и поведенческих паттернов ([ADR 0006](docs/adr/0006-memory-holds-settings-only.md)).
- Официальный Habitify MCP ([ADR 0001](docs/adr/0001-habitify-via-rest.md)).
- Собственный код, production MCP/proxy/runtime, generated copies, служебные проекты и теги, telemetry, self-update и scheduled installation.
- Серверный batch: группа операций выполняется последовательно после одного подтверждения и не откатывается автоматически.
- Permanent delete исходного Inbox item и фоновая запись без подтверждения ([ADR 0003](docs/adr/0003-no-unattended-writes.md), [ADR 0008](docs/adr/0008-cancel-instead-of-delete.md)).
- Публичный SLA поддержки.
